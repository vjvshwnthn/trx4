# TraxnFirstMktg — Radial GTM system hero

Five-page static website. The homepage features a light, compact radial system graphic inspired by the user-provided video: stationary fine-line spokes and concentric rings, three clickable capability nodes, an animated gradient sweep, and progressively revealed capability labels.

## Preview
Open `index.html` in a browser with `styles.css` and `radial.js` in the same folder.

## Deploy
Upload all files to a GitHub repository. Use GitHub Pages or import the repository into a suitable static-site hosting service. No build step required.

## Edit
- `index.html`: hero copy and page content
- `radial.js`: stage names, capability labels and animation timing (3400ms)
- `styles.css`: design, spacing and color

Replace placeholder contact details before publishing.
